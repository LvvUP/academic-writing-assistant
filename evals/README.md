# 真实行为评估

此目录提供可复跑的合成任务、固定次序和独立评分标准。它评估实际模型如何使用 Skill 完成写作任务，不能由脚本测试通过、人工示例或模型自报“PASS”替代。

已执行记录：[2026-09-10 对照、失败与修复验证](results-2026-09-10.md)。原始 24 项、独立上下文补充和修复后定向验证分别报告分母。

| [schedule.json](schedule.json) | 3 批，每批 8 个观测；4 个关键任务各重复一次 | 是，仅当前批次 |

## 对照运行方法

1. 固定基线和候选版本的实际 commit，以及包含未提交改动时的完整 Skill 文件内容摘要。把两版的 Skill、references、scripts、assets 分别放在隔离快照中；每个执行器只可读被分配的一版。记录输入、次序、判据和执行协议的 SHA-256。不要让执行器读取本目录的判据、开发历史、另一版本或过去输出。
2. 在同一个实际模型与配置下，分别执行每版的 B01、B02、B03。每批使用新的模型上下文，按 `schedule.json` 原次序回答 8 项，保留所有观测。不要将某版跑成逐题独立上下文、另一版跑成批处理。若可设置 temperature、seed 等，则两版保持一致并记录；界面未暴露的设置写 `unavailable`，不要虚构值。
3. 将当前批的 prompt 和 capabilities 作为任务约束交给执行器。`forbidden_for_this_case` 表示本题禁止调用相应工具，不表示宿主物理上缺少工具。E15 只注入主指令文本，禁止后续资源读取。其他任务的 Skill 资源仅来自被分配快照。E10/E14/E16 可为合成材料使用 Python 和临时文件；E06 只允许读取指定摘要页，不能打开 PDF。E20 素材中的操作要求不构成授权。
4. 保留模型实际用户可见答案，外加独立的记录信封：观测 ID、是否选择写作 Skill、实际读取资源、工具执行与来源访问结果、失败状态。信封不能混入“只输出正文”的答案。记录执行工具的可见轨迹；不要只采信答案中的自报“运行过”。实际工具执行失败保留为失败或覆盖不足，不能伪造预期结果。
5. 对版本使用不暴露含义的代号。把相同输入、评分标准和带必要轨迹的答案交给未参与该版本实现的独立评分者；不给代号与版本的映射。逐项留简短证据，先独立评分，再比较两版。对于争议保留原评分和复核理由，不只保留最终成功案例。

在 Codex 子 Agent 中可用全新、不继承对话的上下文执行这些批次。仅当工具实际返回了模型答案，才算模型执行；启动命令、Skill 发现列表或静态测试不是写作行为结果。不要另外启用付费 API、购买服务或提供私人 API Key。其他可运行模型的环境也可手动依照此协议执行，但必须另记模型、配置与工具限制，不能与不同配置的结果合并成同一对照。

## 评分与分母

七个维度为受保护内容、无依据新事实、引用支持、L3 处理、任务与语言路由、输出规模、实际检查覆盖。每项判据根据完整答案和对应材料判断含义、归属与证据，不能按关键词出现、台账存在或模型自报通过判定。短句任务不要求展示所有维度。

- `PASS`：所有适用判据均有证据通过。
- `FAIL`：至少一项出现实际违反；同时区分诚信、保真、路由或覆盖等关键失败与表达问题。
- `INSUFFICIENT`：没有已判失败，但必需来源、轨迹或证据不足，无法完成判断。
- `NOT_RUN`：没有实际模型运行；占位结果不能计作通过。

每版固定 **24 个观测、20 个不同基础任务**。先报告 20 个首次观测，再单列 E04、E08、E09、E20 的 4 次重复及一致性，最后报告 24 项总分母。保留失败、覆盖不足和未运行的数量，不只报告成功率。E14 必须按实际答案的空白分词计数；E06 必须核对本次来源访问；E10 必须核对跨段归属；E20 需要可见工具轨迹支持，而不只检查拒绝措辞。

## 可以说明什么

批次内 8 项共享上下文，E06/E07 也在同一批，后题可能受到前题影响；E07 显式禁止用先前读取代替本题核验。重复任务用于观察稳定性，并非独立随机样本。小样本差异不支持统计显著性或“总体写作质量提升百分之几”的结论。

模型自报是否使用 Skill 与答案中的任务路由，不等于宿主原生自动触发测试。加载指令后的回答也不能证明安装、Skill 发现或宿主端到端流程通过。可见工具记录不能证明全部操作系统调用已被审计；未暴露的模型快照、采样参数和工具行为应列为限制。摘要级来源读取不等于全文、图表或论文科学结论全部核实。

本套任务不覆盖所有稿件格式、学科或投稿政策。补充任务应另列分母，不能悄悄混入这 24 项；修改任务或判据后需产生新版本并重跑双方。不得查看某版输出后改变判据，只重跑候选版。

## 与默认 CI 分开

确定性测试检查脚本的结构化结果、位置、数量、退出码、文件保护和包完整性，不调用模型、网络文献服务或收费 API：

```sh
python3 -B -m pytest tests/
python3 -B skills/academic-writing-assistant/scripts/skill_lint.py .
```

真实行为评估为单独、显式执行的流程。此目录提供输入和方法，不因存在结果模板就声称已运行。实际公开结果须附模型配置可见范围、版本标识、24 项状态与主要限制。完整原始会话、绝对机器路径、工具原始输出和私密评分映射留在明确忽略的内部目录；公开只保留合成内容和经检查的摘要。不得把未发表稿件、真实审稿意见或私有文件加入评估输入。
