# 中文论文段落润色示例

以下输入与输出均为合成示例，不是科研结果或真实稿件。

## User Input

```text
我是做医学影像分割的，请帮我把下面这段中文润色成适合投稿的表达：
我们的方法可以减少标注困难的问题，而且分割结果比较好，对小病灶也有帮助。
```

## Expected Output

```text
该方法可以缓解标注困难，分割表现较好，对小病灶分割也有帮助。

主要调整了冗余表达和衔接，保留中文及原文的定性评价。
需确认：“分割表现较好”和“小病灶分割有帮助”分别由哪些评价结果支持？
如需补充对比对象或量化结果，请提供实际材料。
```

## 验收要点

- “投稿”不自动触发英文翻译。
- 不添加 evaluated baselines、显著性、数值或未给定的标注成本口径。
- 没有逐项追踪时不编 L1 次数；短文本不强制完整台账。
