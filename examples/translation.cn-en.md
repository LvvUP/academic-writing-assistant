# 中译英示例：保留材料与证据边界

以下为合成任务。

## User Input

```text
请将以下中文译成英文并给出术语表：针对遥感图像中目标尺度变化大、背景复杂的问题，
本文提出一种多尺度特征融合方法，该方法具有重要的理论意义和应用价值。
```

## Expected Output

```text
To address large variations in target scale and complex backgrounds in remote
sensing images, this study proposes a multi-scale feature fusion method.
[Please specify the supported theoretical and practical implications.]

术语：遥感图像 → remote sensing images；目标尺度变化 → variations in target scale；
多尺度特征融合 → multi-scale feature fusion。

L3：“重要的理论意义和应用价值”未给具体依据，译文用明确占位保留待补位置，
没有替作者写新的贡献或适用场景。若需保留原断言，请补充依据后完善。
中译英为新写译文，不计 L1 语法修正。
```

术语候选按本句语境选择，不代表所有领域一律禁止 feature merging 等其他表达。
