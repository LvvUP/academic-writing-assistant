# 示例索引

以下示例全部为合成材料，用来展示 Skill 在不同任务和学科中的处理方式：哪些地方可以直接改，哪些地方必须保留，哪些修改需要单独说明。

| 示例 | 主要展示 |
|---|---|
| [中文论文润色](polishing.zh.md) | 改善表达，不增加对照对象或数值 |
| [中译英](translation.cn-en.md) | 术语表、无依据的“重要意义”用占位保留 |
| [摘要写作](abstract-writing.md) | 实验尚未完成时如何起草摘要 |
| [引言写作](introduction-writing.md) | 只有少量材料时的结构与占位 |
| [审稿回复](reviewer-response.md) | 区分已完成修改、作者计划与建议 |
| [从表格核对主张](claim-evidence.md) | 用实际表格核对“最佳”“提升”等表述 |
| [术语一致性](terminology-check.md) | 同一概念的不同说法与不同概念的区分 |
| [三种修改力度](writing-modes.md) | 快速润色、标准修订、深度结构审阅 |
| [不同研究类型](research-types.md) | 理论证明、定性研究、综述的证据边界 |
| [人文、法学与经管](humanities-law-economics.md) | 史学阐释、法律规范效力、回归结果的因果表述 |
| [学位论文与开题报告](thesis-and-proposals.md) | 计划与成果、中英文摘要一致性、基金研究基础 |
| [检索范围与隐私](source-bounded-retrieval.md) | 检索授权的边界，不上传私人稿件 |
| [能力缺失时](capability-fallback.md) | 没有 Python 或检索能力时如何继续 |

想看完整规则，请阅读 [SKILL.md](../skills/academic-writing-assistant/SKILL.md)。欢迎按照 [贡献指南](../CONTRIBUTING.md) 补充你所在学科的合成示例。
