# 引言写作示例：仅有少量材料

以下为合成任务，无真实文献或科研数据。

## User Input

```text
帮我写中文引言。方向是中文医疗文本的实体识别。现有方法在通用领域效果好，
但医疗领域标注数据少。我们用了一个基于提示的半监督方法。
```

## Expected Output

```text
中文医疗文本的实体识别面临标注数据不足的问题。现有方法在通用领域表现较好
[请补充支持这一概述的真实文献]。针对医疗领域标注数据较少的情况，本文采用
基于提示的半监督方法研究中文医疗文本的实体识别。

[请补充：该方法如何构造提示、如何使用未标注数据，以及已完成的具体贡献。]

以上依据你给出的材料组织，尚不足以形成完整引言；未补写领域差异、隐私法规、
语料规模比较或迁移失败等外部结论。若需要文献查证，有检索能力时可另行查证实际来源。
```

## 验收要点

保留用户给定研究问题，不把常见领域背景写成作者已证实事实；引用槽不替代缺失论据。
