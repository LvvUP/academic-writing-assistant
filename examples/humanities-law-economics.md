# 人文、法学与经管示例：跟随学科的证据形式

以下输入与输出均为合成示例，不是真实研究、真实法条引用或真实史料。

## 示例一：历史学润色——阐释不升格为定论

### User Input

```text
请润色，适合投稿史学期刊：从这两封信看，他当时大概已经有了离开京城的想法，
不过还说不准。这也说明他对朝廷的政策非常不满。
```

### Expected Output

```text
从这两封书信推断，他当时或已有离京之意，但仍难以确证。

| 原文 | 修改后 | 层级 | 原因 |
|---|---|---|---|
| 这也说明他对朝廷的政策非常不满 | （暂未写入正文） | L3 | 两封书信只涉及离京打算，不足以支持“对政策非常不满”的动机判断；如有其他史料，请提供后再写。 |
```

### 要点

- 改为书面语，保留“推断”“或已”“难以确证”等阐释性限定。
- 不补写离京原因、时间或未提供的史料；动机归因需要材料支持。
- 不要求史学论文提供样本量、实验或统计检验。

## 示例二：法学英译——规范效力不变

### User Input

```text
请译成英文（合成条文，非现行法律）：用人单位应当在用工之日起一个月内与劳动者订立书面劳动合同；
未订立的，不得以此为由拒绝支付劳动报酬。
```

### Expected Output

```text
The employer shall conclude a written employment contract with the employee within one month
from the date on which employment begins. Where no such contract has been concluded, the employer
shall not refuse to pay remuneration on that ground.
```

### 要点

- “应当”对应义务性的 *shall*，“不得”对应 *shall not*；不改为 *should* 或 *may*。
- 期限、起算点和条件关系保持不变。
- 若引用的是具体法律，法律名称、条款号与版本须与原文一致，不凭记忆补写。

## 示例三：经济学润色——回归结果不写成因果

### User Input

```text
请润色：数字金融发展水平越高的城市，居民消费也越高（系数 0.143，在 1% 水平上显著，
城市层面面板数据，控制了城市和年份固定效应）。这说明数字金融促进了居民消费。
```

### Expected Output

```text
在控制城市与年份固定效应后，数字金融发展水平与居民消费呈显著正相关
（系数为 0.143，在 1% 水平上显著；城市层面面板数据）。

L3：原文“促进了”为因果表述。双向固定效应可以控制部分不随时间变化的城市特征，
但当前材料未说明处理反向因果或时变遗漏变量的识别策略。若已有工具变量、
准自然实验等设计，请提供后再按其识别假设写作因果表述。
```

### 要点

- 系数、显著性水平、数据层级与固定效应设定属于锁定区，原样保留。
- 不替作者补写稳健性检验、工具变量或机制分析。
- 改动以台账说明，由作者决定是否采用。
