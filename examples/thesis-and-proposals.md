# 学位论文与开题报告示例：计划、预期与已完成

以下输入与输出均为合成示例，不对应任何真实学校、基金或研究。

## 示例一：开题报告——计划不写成成果

### User Input

```text
帮我润色研究内容：我们会用问卷调查 300 名中学教师，然后分析他们的数字素养跟教学效果
有什么关系，预计能发现数字素养高的老师教学效果更好，最后给教育局提出政策建议。
```

### Expected Output

```text
本研究拟对 300 名中学教师开展问卷调查，分析教师数字素养与教学效果之间的关系，
并据研究结果提出相应的政策建议。

| 原文 | 修改后/候选 | 层级 | 原因 |
|---|---|---|---|
| 预计能发现数字素养高的老师教学效果更好 | 候选：研究假设：教师数字素养与教学效果呈正相关。 | L3 | 原文预设了结果方向；开题阶段宜写为待检验假设，是否采用由作者决定 |
| 最后给教育局提出政策建议 | 据研究结果提出相应的政策建议 | L2 | 建议以研究结果为前提；具体对象是否写明由作者决定 |
```

### 要点

- 使用“拟”“将”描述计划，不写成“已调查”“发现”。
- 300 是计划样本量，原值保留。
- 不添加未提及的抽样方法、量表名称或合作单位。

## 示例二：学位论文——中英文摘要不一致

### User Input

```text
请检查我的中英文摘要是否一致。
中文：……实验结果表明，该方法在两个公开数据集上的 F1 分别提高了 2.1 和 1.7 个百分点。
英文：……Experiments show that the method improves F1 by 2.1% and 1.7% on two public datasets,
demonstrating its superiority over all existing methods.
```

### Expected Output

```text
发现两处不一致：

1. 数值单位：中文为“个百分点”，英文为“%”。百分点（percentage points）与相对百分比含义不同，
   建议英文改为 “by 2.1 and 1.7 percentage points”。
2. 主张范围：英文 “superiority over all existing methods” 在中文摘要中没有对应，
   且超出“两个公开数据集”的比较范围（L3）。建议删除，或改为与实际对比方法一致的表述，
   例如 “outperforming the compared methods on both datasets”（需与正文对比实验核对）。
```

### 要点

- 以中文为准还是以英文为准，由作者确认；工具只指出不一致。
- 百分点与百分比不可互换。
- “all existing methods” 这类全称主张需要相应的比较范围支持。

## 示例三：基金申请书——研究基础只写真实成果

### User Input

```text
帮我把研究基础写得更有说服力：我们组发表过 3 篇相关论文，还有一篇在投。
```

### Expected Output

```text
申请人团队在该方向已有一定研究积累，已发表相关论文 3 篇[请补充论文信息]，
另有 1 篇论文处于投稿阶段[请补充题目与投稿状态]。

说明：“在投”不写成“已发表”或“已录用”；未提供的合作单位、平台、经费与获奖信息不添加。
如需增强说服力，可补充这些论文与本项目的具体关联、已有预实验结果等真实材料。
```
