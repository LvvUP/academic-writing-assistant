# Chinese Academic Style Guide

For polishing Chinese manuscripts, translating into Chinese, and writing Chinese theses. Chinese academic writing has its own failure modes, distinct from the English ones — mainly 口语化, 虚词冗余, and 主张膨胀.

## 语体

中文学术写作应当：书面、准确、克制、术语一致、证据边界清楚。

需要避免的三类：口语表达（"挺好的""特别厉害"）、宣传语气（"完美解决""彻底突破"）、以及虚词堆砌造成的"看起来很学术但没有信息量"。

第三类最隐蔽，也最常见。"本文通过对相关问题进行深入的研究与分析，从而在一定程度上有效地实现了性能的提升" ——去掉虚词后只剩"本文提升了性能"，而具体提升了什么、提升多少，一个字都没说。

## 高频问题

### 1. 虚词与名词化冗余

| 冗余 | 精简 |
|---|---|
| 进行了分析 | 分析了 |
| 实现了……的提升 | 提升了…… |
| 对……进行处理 | 处理…… |
| 起到了……的作用 | 用于…… / 可以…… |
| 具有较好的鲁棒性 | 鲁棒性较好（或直接给数据） |
| 在一定程度上有所改善 | 有所改善（择一保留） |

"进行/实现/开展/起到" + 名词的结构，多数情况下可以还原成动词。这是中文稿压缩空间最大的地方。

### 2. 由于……因此……从而……进而

四段式因果链常见但拖沓，且中间环节往往不承载真实逻辑。拆成两句，只保留真正的因果关系。

### 3. 模糊量化

"很多""较大""明显""大幅""不少"——这些词看似给了信息，实际没有。要么给具体数值，要么改成可核查的表述。

> ❌ 该方法明显提升了检测精度。
> ✅ 该方法在 DatasetA 上将 mAP 提升了 3.2 个百分点。
> ✅（无数据时）该方法在所测试的数据集上提升了检测精度 `[请补充具体数值]`。

### 4. 口语与网络表达

"搞""弄""做出来""效果不错""还可以""比较牛"——直接替换为书面表达。

### 5. "众所周知"

几乎总是可以删除。真正众所周知的事情不需要说明；不众所周知的事情需要引用。

### 6. 第一人称与"笔者"

期刊论文中"本文""本研究""该方法"是标准表述。"我们"在部分学科（尤其理工科合作论文）可接受，"笔者"多见于人文社科单作者论文。按目标期刊惯例选择，不要凭偏好改动。

## 论断强度

强度阶梯，从弱到强：

`可能` < `能够 / 有助于` < `表明 / 说明` < `验证了` < `证明了` < `充分证明了`

规则与英文一致：不得单方面向右移动。向左（更谨慎）可以，但要说明。

特别注意 `证明`。中文的"证明"同时覆盖数学证明和经验支持，翻译成英文的 prove 会变成演绎确定性主张。中文稿内部同样存在这个问题——实验结果宜用"表明""验证了""支持了"，"证明了"应留给真正的推导。

需要谨慎的词：

- **显著**：在论文语境中读作统计显著。未做检验就不要用，改为"一致地""稳定地"或直接给差值。
- **首次 / 首个**：极难辩护，一篇被遗漏的文献即可推翻。至少改为"据我们所知，首次"。
- **最优 / 最先进 / 全面超越**：需绑定到具体对比集合与基准。
- **导致**：断言因果。相关性证据应使用"与……相关""伴随出现"。
- **实时**：有明确的技术含义，需要延迟数据支撑。

## 逻辑连接

推荐使用，能让推理显式化：

因此、进一步地、与此同时、然而、为解决上述问题、基于此、具体而言、值得注意的是、实验结果表明、综上所述

注意两点：一是不要每段开头都用"此外""另外"；二是连接词只应在存在真实逻辑关系时使用，用连接词伪造逻辑连贯是审稿人能读出来的。

## 句子结构

- 主谓宾清晰，避免主语在长定语之后才出现
- 单句不宜过长；一句一个核心意思
- 条件与限定紧贴所修饰的主张，不要放到段末
- 避免多层定语套叠（"基于改进的多尺度特征融合的注意力机制的检测方法"）
- 长短句交替，避免全篇同一节奏

## 中英混排与格式

- 中英文之间通常不加空格（学位论文规范多如此），但全文须统一
- 数字与单位之间加空格：`10 ms`；百分号不加：`95%`
- 标点使用全角中文标点，英文引文内部保留英文标点
- 英文缩写首次出现给出中文全称与英文全称："卷积神经网络（Convolutional Neural Network, CNN）"
- 图表标题格式全文统一
- 参考文献格式遵循目标期刊或学位论文规范，不要中途换风格

## 学位论文与期刊的差异

学位论文（硕博）与期刊论文的写作要求差别很大，用错会被答辩委员或审稿人指出：

| | 期刊论文 | 学位论文 |
|---|---|---|
| 篇幅 | 严格受限 | 要求充分展开 |
| 相关工作 | 精炼，服务于 gap | 需系统综述，体现文献掌握程度 |
| 方法细节 | 可复现即可 | 需完整推导与说明 |
| 失败尝试 | 通常省略 | 往往需要写入，体现研究过程 |
| 第一人称 | 视期刊 | 多用"本文""本研究" |
| 章节结构 | 期刊模板 | 学校规范（绪论、相关技术、方法、实验、总结与展望） |

用户提"毕业论文""学位论文""开题报告"时，按学位论文标准处理，并注意学校模板通常有强制章节要求——不确定时提示用户核对本校规范。
