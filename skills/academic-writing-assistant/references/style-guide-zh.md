# Chinese Academic Style Guide

中文学术表达重在具体、清楚、克制。按作者研究内容改善结构，不通过增加新事实让句子显得具体。

## 语法与结构

“进行了分析→分析了”“对图像进行处理→处理图像”等不改变内容时可直接简化。句子拆合、论点前移和真正重复内容删除归 L2；保留各自条件与引用。

“往往、可能、一定程度、有所、部分”并非天然废词。确认重复同一含义才合并；删除频率、范围或程度信息属于 L3。

避免用“因此、从而”制造不存在的因果关系。已有逻辑可以更清楚地表达，缺失推理作为疑问或建议，不自行补结果原因。

## 具体表述的证据

以下是合成示例，输入已明确提供：同一评测下，方法在 DatasetA 的 mAP 相比 baseline 提高 3.2 个百分点。

可写：该方法在 DatasetA 上的 mAP 比 baseline 高 3.2 个百分点。

如果输入只有“效果比较好”，不能补 DatasetA、指标或差值。可保留定性原意，并在正文之外建议补具体证据。

## 论断强度

显著性、首次性、因果和实时性应与具体材料对应。未看到统计检验不等于作者没做；不要自动把“显著”改成“一致/稳定”。“据我们所知”也不替代首次性证据。

理论证明可以使用“证明”，经验研究通常按证据使用“表明/支持”。不能将这些动词视为跨语境固定阶梯，也不机械降格确有证明的结果。

## 语体与格式

按学科和目标指南选择“本文/本研究/我们/笔者”，不凭偏好强制统一。中英混排、标点、缩写、单位与图表标题遵从实际规范；涉及保护项的格式修改按授权范围处理。

学位论文通常有学校模板；期刊也可能有结构化要求。用户未提供模板时可保留原结构或给中性建议，不把所有学位论文/期刊当成统一格式。
