# Chinese Academic Style Guide

中文学术表达重在具体、清楚、克制。按作者的研究内容改善结构，不靠增加新事实让句子显得具体。

## 语法与结构

“进行了分析→分析了”“对图像进行处理→处理图像”等不改变内容时可直接简化。句子拆合、论点前移和删除真正重复的内容归 L2；保留各自条件与引用。

“往往、可能、一定程度、有所、部分”并非天然废词。确认重复同一含义才合并；删除频率、范围或程度信息属于 L3。

避免用“因此、从而”制造不存在的因果关系。已有逻辑可以表达得更清楚；缺失的推理作为疑问或建议，不自行补写结果原因。

## 常见问题与改法

以下改法只改变表达，不改变事实；遇到承重语言时按 L3 处理。

| 问题 | 示例（合成） | 可改为 | 说明 |
|---|---|---|---|
| 口语化 | 我们弄了一个新模型，效果挺好的 | 本文构建了一个新模型，[效果的具体依据] | “挺好”的具体含义需作者提供，不自行补数值 |
| 空泛开头 | 随着社会的快速发展，……越来越受到人们的关注 | 直接陈述研究问题 | 删除后若作者有具体背景材料，可用其替代 |
| 冗余动词 | 对数据进行了收集和整理 | 收集并整理了数据 | 自由表层 |
| “的”字堆叠 | 基于深度学习的图像的特征的提取方法 | 基于深度学习的图像特征提取方法 | 自由表层 |
| 欧化长定语 | 一种能够在复杂环境下对多种目标进行准确识别的方法 | 一种方法，可在复杂环境下识别多种目标 | “准确”是否保留取决于证据，属承重语言 |
| 被动滥用 | 该问题被我们所解决 | 我们解决了该问题 | 自由表层 |
| 主语缺失或杂糅 | 通过实验表明，该方法有效 | 实验表明，该方法有效 / 通过实验，我们发现…… | 自由表层；“有效”的范围按证据保留 |
| 绝对化 | 彻底解决了……问题 / 完全克服了…… | 改善了……问题 [请补充改善程度的依据] | 强度变化属 L3，需披露 |

## 具体表述的证据

以下是合成示例，输入已明确提供：同一评测下，方法在 DatasetA 的 mAP 相比 baseline 提高 3.2 个百分点。

可写：该方法在 DatasetA 上的 mAP 比 baseline 高 3.2 个百分点。

如果输入只有“效果比较好”，不能补 DatasetA、指标或差值。可保留定性原意，并在正文之外建议补充具体证据。

## 论断强度

显著性、首次性、因果和实时性应与具体材料对应。未看到统计检验不等于作者没做；不要自动把“显著”改成“一致/稳定”。“据我们所知”也不能替代首次性证据。

中文里“显著”既可指统计显著，也常被用作“明显”的同义词。语境不清时提示作者确认：若指统计检验结果，可按目标期刊习惯写作“差异有统计学意义”等；若只是程度描述，可改用“明显”，但不能借此暗示做过检验。

理论证明可以使用“证明”，经验研究通常按证据使用“表明/支持/提示”。这些动词不构成跨语境的固定强度阶梯，也不要机械降格确有证明的结果。

## 标点、数字与单位

以下为中文出版常见规范的要点（如 GB/T 15834《标点符号用法》、GB/T 15835《出版物上数字用法》及国家法定计量单位相关标准）。学校模板或目标期刊另有规定时以其为准；作者统一采用的其他做法也可保留。

- **标点：** 中文语句使用全角标点；英文语句、公式、代码内使用半角标点。并列词语之间多用顿号，书名、期刊名使用书名号，引号内外标点按所在语言处理。
- **中英文混排：** 中文与英文、数字之间是否加空格，按模板或全文一致即可，不强制改变作者的统一做法。
- **数字：** 统计数据、计量、编号通常使用阿拉伯数字；成语、惯用语、概数中的数字通常使用汉字。数值范围的连接号写法保持全文一致。
- **单位：** 使用法定计量单位符号，数值与单位符号之间的空格与全文保持一致；不自动换算单位或改变有效数字。
- **术语首次出现：** 常见写法为“中文全称（English full name，缩写）”，之后使用缩写或中文简称；作者已有约定时遵循作者。

这些都是格式层面的修改。涉及锁定区（数值、单位、引用、编号）时只调整展示，不改内容；统一格式需要用户授权或与全文现有做法一致。

## 语体与格式

按学科和目标指南选择“本文/本研究/我们/笔者”，不凭偏好强制统一。中英混排、标点、缩写、单位与图表标题遵从实际规范；涉及保护项的格式修改按授权范围处理。

学位论文通常有学校模板，期刊也可能有结构化要求，见 [thesis-and-proposals.md](thesis-and-proposals.md)。用户未提供模板时可保留原结构或给中性建议，不把所有学位论文或期刊当作统一格式。

## 中文摘要与关键词

中文摘要常见四要素：目的、方法、结果、结论（医学等领域常用结构化摘要）。按研究类型调整：理论工作写清命题与条件，人文研究写清问题、材料与主要论点，综述写清范围与主要发现。结果部分只写已有结果，未完成的研究保留进度事实，见 [writing-workflows.md](writing-workflows.md) 的 Abstract。

关键词选取文中实际讨论的核心概念，数量按模板要求；不为检索效果添加正文没有讨论的热门词。
