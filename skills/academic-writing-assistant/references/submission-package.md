# Submission Package

投稿材料描述论文内容与作者实际状态。格式可以模板化，作者行为与合规事实不能默认。

## Cover letter

通常包含论文名称与核心发现、与目标期刊的具体联系、材料支持的贡献，以及该 venue 要求的声明。以实际作者指南为准，不复制另一期刊名称。

```text
Dear [Editor or editorial team],

We submit "[Title]" for consideration in [Journal].
[已提供的研究问题、工作和主要发现；没有结果时不补结果]
[与目标期刊范围相关且有材料支持的具体理由]

[请确认后填写：原创性、既往发表与当前投稿状态]
[请确认后填写：全体作者批准情况]
[请确认后填写：适用的利益冲突、伦理与数据可用性声明]

Sincerely,
[对应作者提供的署名与联系方式]
```

不要默认“全体作者批准”“没有利益冲突”“未向其他期刊投稿”。作者已明确确认的事实正常填入，无需重复确认。

## Highlights and graphical abstract text

按目标 venue 的当前条数与长度单位写 highlights；不要将某出版商常用的 85 字符限制推广到全部投稿。用户明确给出“每条 85 字符，含空格”时可据此计数：

```text
python3 -B <skill-root>/scripts/manuscript_audit.py <highlights路径> --limit-chars 85 --per-line
```

每条陈述一个有材料支持的发现，保留范围和比较对象；无数据不编数值。图文摘要说明只覆盖实际看到或用户明确描述的图像内容，不能声称读取了未解析的图。

## AI use disclosure

核查目标期刊/会议、年份、轨道的当前官方作者指南，记录实际来源与适用范围；无检索能力时写“当前政策未核查”。不根据出版商品牌推断所有期刊规则，不宣称语言润色一定豁免。可从目标 venue 的官方网页进入；以下是查证入口，而非已完成政策核验：

实际来源、核对日期与适用范围见 [policy-sources.md](policy-sources.md)。该文件中的日期快照不等于当前投稿政策已核查。

声明只写真实使用目的、工具信息和作者已经完成的复核。以下内容须作者确认，不能原样当已发生事实：

```text
During preparation of this work, [author(s)] used [tool/version if required]
for [实际用途与范围]. [请根据实际完成情况填写人工复核和修改情况].
[按目标 venue 要求填写责任声明].
```

```text
在本文准备过程中，[作者] 使用了 [工具/按要求填写版本]，用于 [实际用途与范围]。
[请根据实际完成情况填写人工复核与修改情况]。[按目标 venue 要求填写责任声明]。
```

不得把实质性起草描述成仅拼写检查，也不能臆测作者已完成复核。是否需声明、声明位置与形式由实际政策决定。

## Author contributions / CRediT

只根据作者提供的分工映射角色。人名、角色和贡献均为事实；不给某位作者默认 Software 或某位导师默认 Funding acquisition。

```text
[作者提供姓名]: [据其实际分工核定的贡献角色].
```

目标 venue 要求 CRediT 时核对其角色命名；用户只给姓名但未给分工时留槽。利益冲突和资助声明同理。

## Suggested reviewers and appeals

候选审稿人不编造。已授权且能检索时可核对公开专业信息与用户提供的利益冲突限制；未检索时给选择条件或整理作者提供名单，不保证不存在未公开关系。

拒稿申诉根据编辑的真实理由和作者提供证据起草；不承诺成功率，不把建议采取的修改或转投写成作者已确定行动。
