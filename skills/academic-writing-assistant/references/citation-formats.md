# Citation Formats / 引用格式

不同学科与期刊使用不同的引用体系。格式问题与“来源是否真实、是否支持论断”是两件事：后者见 [citation-safety.md](citation-safety.md)。

## 默认：保留原有体系

润色、翻译、压缩时保留作者正在使用的引用体系、编号、引用键和脚注位置。不要因为“更学术”就把作者—年份改成顺序编码，或把脚注改成文内引用。

| 常见体系 | 文内形式（示意） | 常见于 |
|---|---|---|
| 顺序编码制 | `[1]`、`[2-4]`、上标 ¹ | 工程、医学、计算机、物理化学；GB/T 7714 的顺序编码制 |
| 作者—年份制 | `(Smith, 2020)`、`（张三，2020）` | 经济、管理、社会科学、心理教育、地学；APA、Harvard、GB/T 7714 的著者—出版年制 |
| 脚注/尾注 | 页下注、章末注 | 法学、历史、哲学、文学、艺术；Chicago notes 等 |
| LaTeX 引用命令 | `\cite{key}`、`\citep{}`、`\citet{}` | 依赖 BibTeX/BibLaTeX 的稿件，见 [latex-and-formats.md](latex-and-formats.md) |

表中“常见于”只是经验分布，具体以学校模板或目标期刊作者指南为准。

## 格式转换：只在授权时进行

用户明确要求“按 GB/T 7714 整理”“改成 APA 第 7 版”等时可以转换，但：

- **只使用已提供的元数据。** 缺失的作者、年份、卷期、页码、DOI、出版地、出版者保留为 `[请补充：卷期]` 等占位，不凭记忆补全，也不从相似文献“借”字段。
- **保持映射。** 顺序编码改作者—年份（或反向）时，逐条核对文内引用与列表条目的对应关系，并在说明中给出映射或提示需人工复核的条目。
- **区分格式与内容。** 统一标点、大小写、斜体、作者缩写属于格式；改变文献类型、版本（预印本/正式版）、页码属于事实，需依据。
- **不确定时说明。** 同一规范不同版本、期刊自定义变体或学校模板存在差异时，说明采用了哪种规则，提示与目标要求核对。

## GB/T 7714 常见要点

中文学位论文和不少中文期刊参照 GB/T 7714《信息与文献 参考文献著录规则》，常见版本为 2015 版；学校或期刊模板可能有自定义要求。

- 文献类型标识示例：`[J]` 期刊、`[M]` 专著、`[C]` 会议录、`[D]` 学位论文、`[R]` 报告、`[S]` 标准、`[P]` 专利、`[N]` 报纸、`[EB/OL]` 网络资源。类型须与真实来源一致，不能为了格式完整而猜测。
- 作者超过规定人数时的省略方式（如“等”“et al.”）、英文作者名的大小写与缩写，以模板为准。
- 网络资源通常需要引用日期与访问路径；没有真实访问记录时留占位。
- 中英文双语参考文献只在期刊要求时制作；英文译名需来自原文献已有的英文题名，不能自行翻译后当作正式题名。

## 英文常见体系要点

- **APA（第 7 版常见）：** 作者—年份；同一作者同年多篇用 a/b 区分；DOI 以 URL 形式给出。
- **IEEE：** 方括号顺序编号，按首次引用顺序排列。
- **Vancouver / AMA：** 医学常用的顺序编码；期刊名缩写规则以期刊要求为准。
- **Chicago：** 有 notes-bibliography（脚注）和 author-date 两种体系，先确认作者使用哪一种。
- **MLA：** 文内作者—页码，多见于语言文学。

这些是一般特征，不能替代目标期刊当前的作者指南。

## 常见可直接指出的问题

可以在说明中提示（不静默修改事实）：

- 文内引用在参考文献列表中找不到，或列表条目从未被引用；
- 编号跳号、重复编号、引用顺序与编号顺序不一致（顺序编码制）；
- 同一文献在不同位置年份、作者拼写不一致；
- 一处使用作者—年份、另一处使用编号的混用；
- 引文页码与直接引语缺失页码（人文、法学常要求）。

这些是一致性提示；某条文献是否真实存在、是否支持对应论断，仍需按 [citation-safety.md](citation-safety.md) 核对。
