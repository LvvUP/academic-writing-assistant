# Workflow Context and Evidence

多任务、长稿或需要证据核对时读取。这是一份简短工作表，不是每次向作者索取的完整表单。

## 轻量上下文

从已有材料识别信息，只询问会实质改变结果且无法合理判断的缺口：

| 字段 | 用途与默认 |
|---|---|
| 任务 | 润色、翻译、起草、压缩、审查、回复等；明确请求优先 |
| 原文语言 / 目标语言 | 未要求翻译时保留源语言，解释跟随用户语言 |
| 学科 / 研究类型 | 依据作者定义与实际设计；经验、理论、定性、综述等适配结构 |
| 章节 / venue | 用于组织和要求；未知 venue 不阻塞普通润色 |
| 篇幅与计量 | 词/字符，是否含空格、标点、标题、引用；具体计数方法 |
| 修改力度 | 用户要求优先，否则按材料长度采用适量标准修订 |
| 已有材料和范围 | 实际可读的正文、表、图、数据、附件、参考文献及版本 |
| 不可改内容 | 作者确认术语、引用、数值、符号、特定句式及核心保护项 |

用户已经提供并确认的信息直接使用，不重复索要。材料互相冲突时定位差异，不自行选较大的值或默认某一版本正确。

## 三种力度

| 模式 | 工作重点 | 交付规模 |
|---|---|---|
| 快速润色 | 拼写、语法、明显冗余和局部衔接；保留结构与主张 | 正文为主，必要疑问一句；一句话纠错可只给正文 |
| 标准修订 | 段落逻辑、术语、表达、证据范围；按需读取附件 | 正文 + 必要 L2/L3 台账 + 未解决事项；L1 只计可追踪项 |
| 深度结构审阅 | 问题与贡献的对应、章节组织、证据缺口、跨章节冲突 | 先给请求的修订正文或可执行审阅结论，再列关键问题、位置和方案 |

力度增加不扩大事实权限。用户只要求结构审查时不自动重写整篇；快速模式也不能隐藏已发现的重要事实冲突。短稿不因选择标准模式就套用长报告。

## 主张与证据对应

对关键结果、贡献、机制解释、外部文献结论、作者行为和理论范围建立短记录：

| 原文主张 | 已提供证据 / 具体位置 | 改写或候选 | 支持状态 | 需确认 |
|---|---|---|---|---|
| [短片段] | [实际文件与页/节/表/行；或消息片段标识] | [短片段] | [下述状态] | [具体缺口] |

仅在主张有争议、多源材料或作者要求时展示，可与 L3 台账合并；记录依据与结果，不要求输出内部推理过程。

支持状态可用：**材料直接支持**、**条件成立时支持**、**仅摘要/片段支持**、**材料冲突**、**材料不足/未检查**。它们描述当前材料的支持程度，不认证研究真实性或整个推导。

写入前区分：

- 作者原值与工具推算值：算术正确仍需比较口径一致。用户授权计算、材料支持时说明算式、单位和舍入；绝对百分点与相对百分比不混用。
- 相关与因果：依据设计、识别假设与证据控制表述，不由相关系数或访谈评价推断干预效果。
- 已完成与未来计划：建议不冒充作者 will/have done；已确认状态不重复询问。
- 作者结果与外部文献：他文数字不等于本研究重跑结果，协议不同保留区别。
- 定理条件与经验观察：有限样本结果不变成全称定理，理论假设不因压缩摘要而消失。

## 实际利用给定材料

表格可读时核对相关行列、标题、单位、脚注、数据划分、指标方向、比较对象和缺失值，再描述结果。全文可读时查找主张所指的真实结果节与定义，不要求作者再次粘贴已有内容。只读到标题、摘要或提取正文时说明图表、批注与全文的未覆盖部分。

不因一个高分就称“最佳”：先核对所有可见对照、指标方向与同协议条件。作者未授权推算时可给建议；已授权且口径齐全时实际计算，不反复确认。

## 长稿连续处理

分节处理时保留简短的已确认术语/符号、结论边界、已读范围与未解决问题。后续发现冲突，引用此前实际位置，不靠记忆补全稿件。结束时在已读范围核对摘要、贡献、结果、讨论、结论，列出未提供或未解析的部分。

## 四级能力与降级

这是可组合的能力清单；有检索能力不要求先有 Python。Skill 描述某工具不意味着宿主已经提供它。

| 能力 | 可做的工作 | 缺失时 |
|---|---|---|
| 1. 指令与文本 | 对可见文字写作、翻译和语义核对 | 无源文时给所需材料或框架，不假造结果 |
| 2. 本地资源读取 | 实际读取需要的 references、术语表和授权材料 | 使用已载入核心；未读资源准确标明 |
| 3. Python 执行 | 对真实文件运行机械保真、术语、结构与计量检查 | 继续文本复核，机械检查记未执行，不编通过结论 |
| 4. 检索及文档解析 | 在授权范围查证文献/政策，读取支持格式的内容 | 分别说明检索、全文、图表或修订层未核查 |

报告示例：“已读取结果节和表 1；已核对给定两条引文摘要；Python 未运行；PDF 图像与 Word 修订层未检查。”这仅是报告形态，实际状态按本次执行填写；短句纠错不必附能力表。
